## 2. Typography Assets

All fonts are statically subsetted and self-hosted via Next.js `next/font/google` at build time. No client-side telemetry or runtime requests connect to external font CDNs.

* **IBM Plex Sans**: SIL Open Font License 1.1 (IBM Corporation). Used for body, navigation, numbers, and UI data labels.
* **Source Serif 4**: SIL Open Font License 1.1 (Adobe Systems Incorporated). Used for editorial titles and headings.
* **Noto Sans Devanagari**: SIL Open Font License 1.1 (Google LLC). Used for Hindi script localization.
* **Noto Sans Telugu**: SIL Open Font License 1.1 (Google LLC). Used for Telugu script localization.

## 3. Vector Icons & Visual Assets

* **Icon Set**: Phosphor Icons (regular stroke weight). All emojis, Lucide icons, and sparkle iconography were stripped in accordance with system design constraints.
* **Drawings & Diagrams**: All concept dependency diagrams and state screen illustrations are drawn using procedural inline SVG code with a consistent 1.5px stroke width.
* **AI Generated Imagery**: Zero AI-generated photographs, faces, or stock illustrations are present in this repository.
